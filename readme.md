---

## 🚀 Installation

1. Download the theme
2. Upload to /wp-content/themes/
3. Activate from WordPress admin
4. Create a menu and assign to "Primary" location

---

## 📋 Requirements

- WordPress 5.0 or higher
- PHP 7.4 or higher
- MySQL 5.6 or higher
